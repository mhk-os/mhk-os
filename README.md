# mhk-os

Moorhuhn Kart: Open Source Edition is a fan remake of the Moorhuhn Kart games in Unity 6. Download latest build from [releases](/mhk-os/mhk-os/releases/latest)

Install mods and asset packs from the Mods menu. Updates select the most recently published compatible release.
